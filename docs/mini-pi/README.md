## 一句话

保留 pi 的四层结构、事件分层、钩子语义分类、会话树、边界草稿机制；砍掉具体功能实现（多 provider、虚拟模型、缓存预热）。

## 四层

```
ai          ->  agent           ->  session        ->  app
模型调用        loop / 工具 / 消息   会话 / 压缩 / 编排    扩展 / 工具实现 / 接口
```

依赖严格单向，用 AST 测试强制。

## 实施顺序

| 阶段 | 产出 | 验收 |

| 1 | `ai/` + `agent/` 的 loop 和 tools | faux provider 跑通工具调用全链路 |
| 2 | `agent/agent.py` + 钩子 | `finish_turn` 三种返回值语义正确 |
| 3 | `session/` 存储与投影 | JSONL 往返一致 |
| 4 | 编排 + 边界 | 重试 / 压缩 / 续跑可确定性复现 |

## 关于本目录

本目录目前只有设计文档，没有代码。

`DESIGN.md` 中的代码片段是**接口定义和关键实现**，不是完整可运行代码——目的是把接缝、类型、契约定死，避免后期返工。
